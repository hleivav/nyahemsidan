Tävlingsbestämmelser

🏆

Herrsingel A (HSA): Bäst av tre set med tiebreak. Förlorarna spelar vidare i Herrsingel B

🏆

Övriga klasser: Bäst av tre set med "NoAd" i de två första seten och supertiebreak i avgörande set.

📋

NoAd: Vid ställningen 40-lika spelas endast en avgörande poäng. Mottagaren bestämmer i vilken ruta serven ska slås.

📋

Supertiebreak: Det avgörande set spelas till 10 poäng, med två bollars marginal.

👥

Klass B: Icke-seedad spelare/dubbelpar som förlorar i första matchen bildar Klass B.

⚙️

Tävlingsledningen kan besluta att korta ner matcher, mest troligt HSA, samt minska ner eller ta bort Klass B om tidsbrist eller annat skäl föreligger .

📚

SvTF:s bestämmelser gäller. SJTK:s Tävlingskommitté avgör seedningen.

🔄

Reserv kan sättas in vid avhopp innan turneringsstart.
