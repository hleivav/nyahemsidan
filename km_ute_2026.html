Blir det fler än 16 spelare blir det kval inomhus, STC eller Järfälla. Vid 16 spelare blir det spel från fredag.

📋

Tävlingsbestämmelser

🎾

Cupspel. Herrsingel A (HSA): Bäst av tre set med tiebreak. Övriga klasser: bäst av tre set med "NoAd" i de två första seten och supertiebreak i avgörande set. Icke-seedad spelare som förlorar i första matchen bildar Klass B.

⏱️

Tävlingsledningen kan besluta att korta ner matcher, mest troligt HSA, samt minska ner eller ta bort Klass B om tidsbrist eller annat skäl föreligger.

🔢

"NoAd" vid 40–lika spelas avgörande poäng. Mottagaren väljer serveruta.

🔟

Supertiebreak innebär att det avgörande set spelas till 10 poäng, med två bollars marginal.

🔄

Skulle det mot förmodan bli något avhopp innan turneringsstart, så kan reserv sättas in.

📖

För övrigt gäller SvTF:s bestämmelser. SJTK:s Tävlingskommitté avgör seedningen.

📚

I övrigt se SJTK:s tävlingsanvisningar på sjtk.se/tavlingsanvisningar.

👤

Medlemskap i SJTK krävs för deltagande.
